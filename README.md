# CIMC Record Viewer

A robust digital record viewer and archiving system designed specifically for the City of Ilagan Medical Center (CIMC). This system streamlines how hospital staff manage patient information by digitizing physical records, enabling fast retrieval, and providing built-in PDF and image manipulation tools for viewing medical documents.

## Features

* **Patient Folder System:** A comprehensive digital filing system that organizes patient records into easily accessible, centralized profiles.
* **Advanced Search Functionality:** Rapidly query and locate specific patient files across the database to minimize administrative wait times.
* **Integrated PDF & Image Viewer:** View, manage, and manipulate PDF documents and scanned images directly within the browser without needing third-party software.
* **Secure Archiving:** Reliable data storage designed to maintain the integrity and accessibility of historical hospital records.

## Tech Stack

* **Backend:** PHP / Laravel
* **Frontend:** React / TypeScript / Tailwind CSS
* **Database:** SQL Server
* **Architecture:** RESTful API with a singular-model convention (e.g., `Patient`)
